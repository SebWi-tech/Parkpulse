# ParkPulse
Park smart. Get rewarded.

## Vision
ParkPulse connects parking discovery, transparent payment,
shopping discounts and loyalty rewards in one user journey.

## Core features
- Find and compare suitable parking facilities
- View parking conditions and simulated availability
- Manage a parking session
- Redeem shopping discounts
- Complete simulated payments
- Collect stamps and unlock parking rewards

## Prototype scope
We use fictional parking data, hypothetical partner offers
and simulated transactions.

Real payments, guaranteed reservations, barrier control
and live charging integrations are outside the first version.

## Project status
Requirements and concept development.
Implementation and test results will be documented as work progresses.
